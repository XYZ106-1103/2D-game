# TETHERFALL

비 내리는 사이버펑크 메가시티 **베스퍼**를 와이어 하나로 가로지르는 2D 픽셀 액션 플랫포머.
Phaser 3 · TypeScript · Vite · WebGL(GLSL) · Web Audio API.

> 현재 버전: **v2.0 — CHAPTER 1·2** (11개 스테이지 · 보스 2종 · 챕터 간 연출 · 최종 엔딩)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 확인
npm test           # 로프 감김/레이캐스트 결정론 테스트
```

데스크톱 브라우저(Chrome/Edge/Firefox 최신) + 키보드·마우스를 권장합니다.

## 조작

| 입력 | 동작 |
|------|------|
| A / D | 이동 · 스윙 가속(펌핑) |
| Space | 점프 (와이어에 매달린 상태 = 점프 해제) |
| 마우스 좌클릭 (홀드) | 와이어 발사·유지, 떼면 관성 유지한 채 해제 |
| 스윙 중 좌클릭 다시 | 다음 목표로 즉시 연속 그래플 |
| 적에게 와이어 | **돌진 일격** — 끌려가며 강타, 방패 가드 파괴 |
| W / S · 휠 | 와이어 감기 / 풀기 |
| Shift | 대시 (방향키로 8방향, 공중 1회 · 와이어 연결/적중 시 충전, 무적 판정) |
| 마우스 우클릭 / J | 공격 (지상 2단 콤보, 공중 회전 베기 · 적 탄환 반사) |
| Esc | 일시정지 |

키보드 전용: K/Z 와이어(가장 가까운 노드 자동 조준), X 공격, C 점프, L 대시.

## 챕터 1 구성

| 스테이지 | 테마 | 핵심 요소 |
|----------|------|-----------|
| 1. 9구역: 잠긴 옥상 | 보랏빛 옥상, 달 | 그래플 튜토리얼, 감아 오르기, 유리 외벽, 대시 간극, 장거리 스윙 |
| 2. 하층 시장 | 따뜻한 스모그, 한글 간판 골목 | 이동 노드, 증기 분출구, 붕괴 격자 다리, 혼성 전투 |
| 3. 레테 타워 외벽 | 구름바다 위 달빛, 돌풍 | 112행 수직 등반, 곤돌라 노드, 증기 기둥, 저격 포탑 |
| 4. 기록관 | 첨탑 꼭대기 | 3페이즈 보스전 → 엔딩 |

**적**: 추적 드론(예고 후 돌진), 센트리 포탑(조준선 → 고정 → 3연사, 탄 반사 가능),
레테 방패병(정면 방어, 후방·상단·돌진 일격에 취약).
**보스 기록관**: 팔 노드 파괴 → 드론 소환 → 코어 노출 + 바닥 감전 + 방사 탄막, 슬램 충격파, 추적 레이저.

## 챕터 2 — 첨탑의 심장

기록관을 쓰러뜨린 이온은 첨탑 안으로 들어가, 레테가 도시에서 훔친 '그 한 시간'의 정체와 자신이 스스로를 지운 이유를 알게 된다.
스테이지마다 **전용 타일셋 · 배경 · 날씨 · 음악 · 고유 기믹**이 있습니다(색만 바꾼 스테이지 없음).

| 스테이지 | 장소 | 고유 기믹 |
|----------|------|-----------|
| 5. 콜드 아카이브 | 얼어붙은 서버 홀, 서리 | 시간차 보안 레이저, 천장 랙 스윙(냉각 유리는 불가), 냉각 상승 기류, 순풍 간극, 바닥 스윕 레이저 |
| 6. 기억 정제소 | 레테 원액 저장조, 불씨 | 흔들림으로 예고하는 압착기, 붕괴 격자 + 원액 웅덩이, 부유 기뢰, **차오르는 원액 탈출 수직갱** |
| 7. 중력 코어 | 녹턴의 고치가 떠 있는 구형 공간 | 저중력 구역(긴 체공), **중력 우물**(핵에 와이어를 걸어 공전), 저중력 리프트 |
| 8. 침묵의 시간 | 그날 밤의 기억 — 흑백 와이어프레임 도시, 멈춘 빗방울 | **박자에 맞춰 바뀌는 기억 발판**, 내 경로를 따라오는 **잔상(과거의 이온)** |
| 9. 공중 정원 | 대리석 테라스, 유리 돔, 꽃잎 | 튕겨 올리는 **발광 꽃**, 와이어를 걸면 켜지는 **빛의 다리 스위치** |
| 10. 방송탑 | 폭풍 속 송신 마스트 | **피뢰침 낙뢰**(충전 → 반경 타격), **송출 패드**(고리에 맞춰 점프하면 높이 발사) |
| 11. 녹턴 | 새벽, 송신 접시 | 최종 보스 |

**새 적**: 부유 기뢰(접근 → 점멸 → 폭발, 먼저 베거나 와이어 일격으로 무력화),
잔상(1.4초 전 플레이어의 움직임을 그대로 재생, 한 번 베면 흩어졌다 재형성, 와이어로 잡을 수 없음).

**최종 보스 녹턴 — 기억을 먹는 나방**: 날개의 칸 하나하나가 훔친 밤을 재생하는 화면.
1페이즈 날개 렌즈 4개(비늘 탄막·돌풍·궤적 예고 급강하) → 2페이즈 **일식**(화면이 어두워지고 빛나는 렌즈와 플레이어 주변만 보임, 나방떼) →
3페이즈 찢어진 날개, 노출된 코어와 틈이 있는 기억 고리. 렌즈를 맞히면 날개를 접어 밀쳐내므로 패턴 사이를 노려야 합니다.

## 핵심 시스템

- **물리 기반 그래플링** — 120Hz 고정 스텝, 늘어나지 않지만 처질 수 있는 로프 제약, 각운동량 보존 감기,
  접선 방향 펌핑, 해제 관성 + 부스트, 지형 모서리 **로프 감김/풀림**, 움직이는 노드 추종, 조준 보조(옵션), 입력 버퍼링.
- **전투** — 휘두를 때마다 고유 ID를 가진 히트박스, 히트스톱·흔들림·백색 플래시·충격 스파크, 공중 타격 반동,
  콤보 카운터, 탄 반사, 방어(블록) 반동, 처치 폭발·파편.
- **절차적 픽셀 아트 파이프라인** — `tools/art`의 리그 렌더러가 플레이어(111프레임)와 방패병을 같은 광원·외곽선 규칙으로,
  보스 팔은 24각도로 굽습니다. 결과물은 표준 PNG 스프라이트 시트라 손으로 그린 시트로 그대로 교체할 수 있습니다.
- **재질 키트(타일셋) 6종** — `tools/art/kits.ts`: 서버 랙, 리벳 철판, 흑요석 모노리스, 와이어프레임 복셀, 대리석, 적백 철골.
  같은 레이아웃(오토타일 마스크·내부 장식·통과 불가 면·일방 발판·위험 지형·배경 벽·붕괴 블록)을 재질마다 새로 그립니다.
- **녹턴 날개** — 날갯짓 프레임을 축 방향 원근으로 미리 구워 회전·확대 없이 픽셀 그리드를 유지합니다(`tools/art/boss2.ts`).
- **일식 셰이더** — 포스트FX에 어둠 + 빛 웅덩이 + 밝은 픽셀 보존 패스를 추가(디더 양자화).
- **비트맵 한글 폰트** — Galmuri(OFL) BDF를 직접 파싱해 KS X 1001 한글 2,350자 + ASCII를 아틀라스로 굽습니다.
- **카메라** — 진행 방향으로 120px 앞을 비추는 160px 데드존 추적, 방향 전환은 일정 시간 이동해야 확정, 세로는 착지할 때만 재정렬(화면 밖으로 벗어날 때만 예외). 와이어를 걸어야 할 노드나 올라가야 할 발판이 바로 위에 있으면 화면을 조금(최대 52px) 올려 보여 줍니다.
- **조작 보정** — 코요테 타임 0.12초(발판을 벗어난 직후 점프 허용), 점프 입력 버퍼 0.15초(착지 직전 입력을 착지 순간 실행), 최소 점프 높이 보장.
- **정수 배율 픽셀 퍼펙트** — 내부 480×270, 장치 픽셀 기준 정수 배율, 블룸/그레이딩/저체력 경고 GLSL 패스도 내부 해상도에서 계산.
- **사운드** — 효과음 50여 종과 스테이지별 음악 12곡을 Web Audio로 실시간 합성. 교전 시 퍼커션 레이어가 더해지는 동적 음악.
