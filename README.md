# TETHERFALL

비 내리는 사이버펑크 메가시티 **베스퍼**를 와이어 하나로 가로지르는 2D 픽셀 액션 플랫포머.
Phaser 3 · TypeScript · Vite · WebGL(GLSL) · Web Audio API.

> 현재 버전: **v1.0 — CHAPTER 1** (4개 스테이지 + 보스 + 엔딩, PHASE 1–10 완료)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 확인
npm test           # 로프 감김/레이캐스트 결정론 테스트
```

데스크톱 브라우저(Chrome/Edge/Firefox 최신) + 키보드·마우스를 권장합니다.

## 조작

| 입력 | 동작 |
|------|------|
| A / D | 이동 · 스윙 가속(펌핑) |
| Space | 점프 (와이어에 매달린 상태 = 점프 해제) |
| 마우스 좌클릭 (홀드) | 와이어 발사·유지, 떼면 관성 유지한 채 해제 |
| 스윙 중 좌클릭 다시 | 다음 목표로 즉시 연속 그래플 |
| 적에게 와이어 | **돌진 일격** — 끌려가며 강타, 방패 가드 파괴 |
| W / S · 휠 | 와이어 감기 / 풀기 |
| Shift | 대시 (방향키로 8방향, 공중 1회 · 와이어 연결/적중 시 충전, 무적 판정) |
| 마우스 우클릭 / J | 공격 (지상 2단 콤보, 공중 회전 베기 · 적 탄환 반사) |
| Esc | 일시정지 |

키보드 전용: K/Z 와이어(가장 가까운 노드 자동 조준), X 공격, C 점프, L 대시.

## 챕터 1 구성

| 스테이지 | 테마 | 핵심 요소 |
|----------|------|-----------|
| 1. 9구역: 잠긴 옥상 | 보랏빛 옥상, 달 | 그래플 튜토리얼, 감아 오르기, 유리 외벽, 대시 간극, 장거리 스윙 |
| 2. 하층 시장 | 따뜻한 스모그, 한글 간판 골목 | 이동 노드, 증기 분출구, 붕괴 격자 다리, 혼성 전투 |
| 3. 레테 타워 외벽 | 구름바다 위 달빛, 돌풍 | 112행 수직 등반, 곤돌라 노드, 증기 기둥, 저격 포탑 |
| 4. 기록관 | 첨탑 꼭대기 | 3페이즈 보스전 → 엔딩 |

**적**: 추적 드론(예고 후 돌진), 센트리 포탑(조준선 → 고정 → 3연사, 탄 반사 가능),
레테 방패병(정면 방어, 후방·상단·돌진 일격에 취약).
**보스 기록관**: 팔 노드 파괴 → 드론 소환 → 코어 노출 + 바닥 감전 + 방사 탄막, 슬램 충격파, 추적 레이저.

## 핵심 시스템

- **물리 기반 그래플링** — 120Hz 고정 스텝, 늘어나지 않지만 처질 수 있는 로프 제약, 각운동량 보존 감기,
  접선 방향 펌핑, 해제 관성 + 부스트, 지형 모서리 **로프 감김/풀림**, 움직이는 노드 추종, 조준 보조(옵션), 입력 버퍼링.
- **전투** — 휘두를 때마다 고유 ID를 가진 히트박스, 히트스톱·흔들림·백색 플래시·충격 스파크, 공중 타격 반동,
  콤보 카운터, 탄 반사, 방어(블록) 반동, 처치 폭발·파편.
- **절차적 픽셀 아트 파이프라인** — `tools/art`의 리그 렌더러가 플레이어(111프레임)와 방패병을 같은 광원·외곽선 규칙으로,
  보스 팔은 24각도로 굽습니다. 결과물은 표준 PNG 스프라이트 시트라 손으로 그린 시트로 그대로 교체할 수 있습니다.
- **비트맵 한글 폰트** — Galmuri(OFL) BDF를 직접 파싱해 KS X 1001 한글 2,350자 + ASCII를 아틀라스로 굽습니다.
- **정수 배율 픽셀 퍼펙트** — 내부 480×270, 장치 픽셀 기준 정수 배율, 블룸/그레이딩/저체력 경고 GLSL 패스도 내부 해상도에서 계산.
- **사운드** — 효과음 40여 종과 스테이지별 음악 5곡을 Web Audio로 실시간 합성. 교전 시 퍼커션 레이어가 더해지는 동적 음악.

## 개발용 플래그

- `?dev=1` — 숫자키 1~5로 현재 스테이지의 체크포인트 순간 이동
- `?stage=N` — 새 게임 시작 시 N번(0부터) 스테이지로 바로 진입
