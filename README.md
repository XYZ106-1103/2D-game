# TETHERFALL

비 내리는 사이버펑크 메가시티 **베스퍼**를 와이어 하나로 가로지르는 2D 픽셀 액션 플랫포머.
Phaser 3 · TypeScript · Vite · WebGL(GLSL) · Web Audio API.

> 현재 버전: **v0.1 — 첫 번째 플레이어블 빌드** (PHASE 1–4 완료, 6·7 기반 포함)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 확인
npm test           # 로프 감김/레이캐스트 결정론 테스트
```

데스크톱 브라우저(Chrome/Edge/Firefox 최신) + 키보드·마우스를 권장합니다.

## 조작

| 입력 | 동작 |
|------|------|
| A / D | 이동 · 스윙 가속(펌핑) |
| Space | 점프 (와이어에 매달린 상태 = 점프 해제) |
| 마우스 좌클릭 (홀드) | 와이어 발사·유지, 떼면 관성 유지한 채 해제 |
| 스윙 중 좌클릭 다시 | 다음 목표로 즉시 연속 그래플 |
| W / S · 휠 | 와이어 감기 / 풀기 |
| Shift | 대시 (방향키로 8방향, 공중 1회 · 와이어 연결 시 충전) |
| 마우스 우클릭 / J | 공격 (지상 2단 콤보, 공중 회전 베기) |
| Esc | 일시정지 |

키보드 전용: K/Z 와이어(가장 가까운 노드 자동 조준), X 공격, C 점프, L 대시.

## 핵심 시스템

- **물리 기반 그래플링** — 120Hz 고정 스텝, 늘어나지 않지만 처질 수 있는 로프 제약, 각운동량 보존 감기,
  접선 방향 펌핑, 해제 시 관성 + 부스트, 지형 모서리 **로프 감김/풀림**, 조준 보조, 입력 버퍼링.
- **절차적 픽셀 아트 파이프라인** — `tools/art`의 리그 렌더러가 캐릭터 111프레임(12종 애니메이션 + 각도별
  스윙/발사/대시 변형)을 동일한 광원·외곽선 규칙으로 굽습니다. 결과물은 표준 PNG 스프라이트 시트라
  손으로 그린 시트로 그대로 교체할 수 있습니다.
- **비트맵 한글 폰트** — Galmuri(OFL) BDF를 직접 파싱해 KS X 1001 한글 2,350자 + ASCII를 아틀라스로 굽습니다.
- **정수 배율 픽셀 퍼펙트** — 내부 480×270, 장치 픽셀 기준 정수 배율, 블룸/색보정 GLSL 포스트 패스도 내부 해상도에서 계산.
- **연출** — 히트스톱, 슬로모션, 트라우마 기반 화면 흔들림, 속도 잔상, 스카프 Verlet 2차 운동, 5겹 패럴랙스,
  공중 교통, 서치라이트, 3층 비 + 지붕 물보라, 번개, 네온 깜빡임.
- **사운드** — 모든 효과음과 음악을 Web Audio로 실시간 합성 (오디오 파일 없음).
