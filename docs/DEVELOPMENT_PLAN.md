# TETHERFALL — 개발 계획서

> 사이버펑크 픽셀 아트 그래플링 액션 플랫포머
> Phaser 3 · TypeScript · Vite · WebGL/GLSL · Web Audio API

---

## 0. 디자인 필러 (Design Pillars)

| # | 필러 | 의미 |
|---|------|------|
| 1 | **와이어가 곧 게임이다** | 그래플링은 순간이동이 아닌 물리 진자 운동. 관성·각운동량·로프 감김이 살아 있어야 한다. |
| 2 | **움직임만 봐도 완성도가 보인다** | 모든 프레임은 일관된 픽셀 그리드, 명암 단계, 실루엣을 가진다. 스카프·코트 같은 2차 운동이 속도감을 전달한다. |
| 3 | **비 내리는 네온의 밀도** | 최소 5겹 패럴랙스, 비·안개·광고판·교통 등 환경이 항상 움직인다. |
| 4 | **짧고 강한 피드백** | 히트스톱, 흔들림, 잔상, 섬광은 상황에 맞춰 절제해서 쓴다. |
| 5 | **기능 수보다 완성도** | 새 기능은 기존 기능이 충분히 다듬어진 뒤에만 추가한다. |

## 1. 세계관 요약

- **도시**: 베스퍼(VESPER) — 스모그 아래 영원히 밤인 수직 메가시티.
- **기업**: 레테 다이내믹스(LETHE Dynamics) — 시민의 기억을 클라우드 "아카이브"에 백업·편집하는 기업.
- **사건**: "침묵(The Silence)" — 어느 밤, 도시 전체가 같은 한 시간을 잊어버렸다. 기업은 서버 장애라고 발표했다.
- **주인공**: 이온(ION) — 9구역 폐허에서 깨어난 배달부. 이름도 과거도 없이, 팔에 와이어 건틀릿 "테더"가 결합되어 있다.
- **동료**: 모스(MOTH) — 건틀릿 속 단편화된 AI. HUD를 통해 말을 건다.
- 스토리는 대화, 환경 연출(거대 광고판·기업 탑), 수집형 기록(메모리 로그)으로 전달한다.

## 2. 기술 구조

```
tetherfall/
├─ index.html                 정수 배율 캔버스 호스트
├─ src/
│  ├─ main.ts                 Phaser 부팅, 정수 배율(장치 픽셀 기준) 스케일러
│  ├─ config.ts               해상도·물리·조작 튜닝 상수
│  ├─ core/                   입력, 수학, 저장, 이벤트, 고정 스텝 루프
│  ├─ physics/                AABB-타일 충돌, 레이캐스트(DDA), 로프 제약
│  ├─ entities/               Player(상태 기계), GrappleHook, Scarf(Verlet)
│  ├─ world/                  Level 로더·오토타일·장식, Parallax, Weather
│  │  └─ levels/              ASCII 레벨 데이터
│  ├─ fx/                     파티클, 잔상, 카메라 디렉터, 히트스톱, GLSL 포스트FX
│  ├─ audio/                  Web Audio 합성 SFX, 앰비언스, 절차적 음악 시퀀서
│  ├─ ui/                     비트맵 텍스트, 메뉴, 패널
│  ├─ scenes/                 Boot, Title, Intro, Game, Hud, Pause, Options, Controls
│  └─ data/                   대사·기록 텍스트
├─ tools/                     빌드 타임 에셋 파이프라인 (Node, 의존성 없음)
│  ├─ lib/png.ts              PNG 인코더
│  ├─ art/                    절차적 픽셀 아트 생성기 (리그, 타일셋, 배경, 프롭, FX, UI)
│  ├─ bake-art.ts             → public/assets/sprites|bg/*.png + *.json
│  └─ bake-fonts.ts           Galmuri BDF → BMFont(PNG+XML)
└─ public/assets/             게임이 로드하는 표준 스프라이트 시트·아틀라스·폰트
```

### 핵심 설계 결정

1. **에셋 파이프라인 분리** — 픽셀 아트는 `tools/art`의 생성기가 표준 스프라이트 시트(PNG + JSON 메타데이터)로 굽는다. 게임은 일반 PNG만 로드하므로, 이후 Aseprite로 손으로 그린 시트로 교체해도 코드 변경이 없다.
2. **절차적 픽셀 리그** — 캐릭터는 관절 포즈 → 부위별 래스터화 → 광원 방향 명암 → 접촉 그림자 → 외곽선(셀아웃) 순서로 렌더링된다. 머리·몸통은 손으로 찍은 스탬프를 RotSprite 방식으로 회전해 어떤 각도에서도 픽셀 그리드가 깨지지 않는다.
3. **자체 물리** — Arcade Physics 대신 120Hz 고정 스텝 + 렌더 보간. 로프 제약·감김을 정밀하게 제어하기 위함.
4. **픽셀 퍼펙트** — 내부 480×270, `pixelArt`, `roundPixels`, 장치 픽셀 기준 정수 배율. 포스트FX도 내부 해상도에서 계산.
5. **비트맵 폰트** — Galmuri(OFL) BDF를 직접 파싱해 KS X 1001 한글 2,350자 + ASCII를 아틀라스로 굽는다. 브라우저 안티앨리어싱이 전혀 없다.

| **PHASE 8** 보스·스토리 | 레테 집행자 보스(3페이즈), 컷신, 대화 시스템, 로그 | 영화 같은 보스전 |
| **PHASE 9** 완성도 개선 | 튜닝, 접근성(키 리매핑, 흔들림 끄기), 저장, 연출 다듬기 | 플레이테스트 피드백 반영 |
| **PHASE 10** QA | 성능 프로파일링, 경계 사례, 브라우저 호환 | 크래시·소프트락 0 |

- 전투 규칙: 방패 정면 방어 / 후방·상단 피격 / 돌진 일격 가드 브레이크 / 탄 반사
- `npm test`: 로프 감김·풀림·길이 보존, 레이캐스트
